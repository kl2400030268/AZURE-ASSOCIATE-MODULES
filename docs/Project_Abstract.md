# Project Abstract

## Azure Application Insights Instrumentation for a Web Application

The project focuses on building a web application and monitoring its behavior using Azure Application Insights. The main objective is to identify slow requests, failed dependencies, exceptions, and performance bottlenecks in the application.

The application will use React for the frontend, Spring Boot for the backend, and MySQL for storing application data. OpenTelemetry will be used as the instrumentation layer to collect telemetry such as requests, dependencies, traces, exceptions, and performance metrics.

Azure Application Insights will be used to monitor and analyze the collected telemetry. The system will support end-to-end request tracing and dependency mapping, helping identify where a request becomes slow or fails. The project will also demonstrate how Application Insights can be used to analyze application performance, monitor failures, and identify potential bottlenecks.

The project aims to demonstrate the use of cloud-based application monitoring and observability for a web application.
